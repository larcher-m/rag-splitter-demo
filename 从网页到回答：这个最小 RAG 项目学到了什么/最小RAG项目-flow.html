最小 RAG 的五个层次

每一层都可以单独观察、单独调试，再把它们串成完整的“检索增强生成”链路。

1. Loader

读取网页内容

CSS selector 缩小范围

输出 Document

2. Splitter

按句末标点切分

控制 chunk 大小

overlap 保留上下文

3. Embedding

文本变向量

文档与问题进入同一空间

语义可以计算

4. Retrieve

按相似度排序

取回 top-k 片段

不要混淆距离与相似度

5. Generate

拼接上下文

明确资料与问题

模型基于资料回答

可观察性优先：在进入下一层前，先检查上一层的输出。比如 selector 是否拿到正文、chunk 是否合理、embedding 是否返回向量、检索结果是否真的相关。
